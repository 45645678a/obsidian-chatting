# Provenance and attribution

This is an unofficial, independently maintained fork of
[o1xhack/obsidian-chatting](https://github.com/o1xhack/obsidian-chatting),
based on upstream release **0.4.2**, commit
`f642d3085582cd5e8af177c6f91c2c2d74e6ef7a`.

The upstream project derives from
[omarshahine/obsidian-chat](https://github.com/omarshahine/obsidian-chat).
The original MIT license and all existing copyright notices for Omar Shahine,
Yuxiao (o1xhack), and Thomas Schierl are retained in `LICENSE`.

The study-workflow enhancements in `enhancements/` and the added styles were
developed in October 2026. They are maintained in this fork by
[45645678a](https://github.com/45645678a) and distributed under the same MIT
license. Their presence does not imply endorsement by any upstream author.

Fork release 0.4.3 packages these changes as a reproducible post-build layer,
adds portable tests, documents the fork's installation and data storage, and
marks the distributed package as desktop-only. It does not include personal
settings, credentials, chat databases, notebooks, or machine-specific install
and live-verification scripts.

Bundled dependency license texts are included in `THIRD_PARTY_NOTICES.md`.
